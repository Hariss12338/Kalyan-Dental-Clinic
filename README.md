# Kalyan Dental Clinic – Dr. Sabina | Premium Dental Website

## Overview
A premium, modern, and immersive dental clinic website built with cutting-edge web technologies. This website showcases 22+ years of trusted dental excellence with Dr. Sabina.

## 🎨 Design Features

### Visual Design
- **Luxury Modern Aesthetic**: Dark gradient backgrounds with cyan and blue accents
- **Glassmorphism UI**: Frosted glass effects with blur backdrops
- **Smooth Animations**: GSAP-powered cinematic animations
- **Dynamic Scrolling**: Lenis smooth scrolling with parallax effects
- **Floating Elements**: Layered animations and floating cards
- **Gradient Overlays**: Premium gradient color schemes
- **Responsive Design**: Fully optimized for all devices

### Interactive Features
- **Magnetic Buttons**: Buttons that follow cursor movement
- **Animated Counters**: Numbers that count up on scroll
- **Hover Effects**: 3D transformations and glow effects
- **Mouse-Follow Effects**: Interactive glow that tracks cursor
- **Scroll Triggers**: Animations triggered by scroll position
- **Section Reveals**: Text and elements reveal on scroll

## 🚀 Technology Stack

### Frontend
- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework
- **JavaScript (ES6+)**: Modern JavaScript
- **GSAP**: Professional animation library
- **ScrollTrigger**: Scroll-based animations
- **Lenis**: Smooth scrolling library

### Libraries & Tools
```html
<!-- Tailwind CSS -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- GSAP & ScrollTrigger -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/ScrollTrigger.min.js"></script>

<!-- Lenis Smooth Scrolling -->
<script src="https://cdn.jsdelivr.net/gh/studio-freight/lenis@1.0.29/bundled/lenis.js"></script>
```

```html

```

### Modify Services
Add/remove service cards in the Services section. Each card follows the same structure with icon, title, and description.

### Update Doctor Information
Edit Doctor section content with qualifications and specializations.

### Change Colors
Modify CSS variables in `css/styles.css`:
```css
:root {
    --primary: #06b6d4;
    --secondary: #3b82f6;
    /* ... other colors */
}
```
